# Chat Seeding Script

This document explains how to generate realistic chat history for the **GENERAL** channel of the **EZProject** project.

## Prerequisites
- Node.js (v18+ recommended)
- MongoDB running locally or reachable via `MONGO_URI`
- The project must already contain:
  - A `Project` document with `name: "EZProject"`
  - All team members as `User` documents (their emails are stored in the DB)
  - A `ChatRoom` named **GENERAL** with `type: 'GENERAL'` for that project (the script **will NOT create** a new channel)

## Usage
```bash
# Install dependencies (if not already installed)
npm install   # or yarn install – installs mongoose etc.

# Run the seeding script
node Backend/seed_chat_messages.js
```
The script will:
1. Connect to MongoDB using the URI from `.env` (or default `mongodb://localhost:27017/ezproject`).
2. Locate the EZProject and its GENERAL chat room.
3. **Delete** all existing messages in that room.
4. Generate chat messages for **10 June 2026 → 15 July 2026**
   - 50‑300 messages per day (higher on deadline‑heavy days).
   - Random timestamps throughout the day (no two messages share the exact same `createdAt`).
   - Mixed content:
     - 60 % work‑related sentences (e.g., "Task Payment ai làm?")
     - 40 % casual talk, slang, emojis, short replies.
     - 10‑20 % mentions (`@username`).
     - 20‑30 % tags (`#IT`, `#BIZ`, …).
     - ~5 % share‑task announcements (e.g., "Bảo vừa giao cho Khánh task Fix Payment").
     - 5‑10 % with placeholder media URLs.
     - ~20 % are replies to earlier messages.
5. Log daily stats and write a `chat_seed_summary.json` file containing the number of messages generated per day.

## Customisation
Edit the constants at the top of the file to change:
- `START_DATE` / `END_DATE`
- `MIN_PER_DAY`, `MAX_PER_DAY`
- `deadlineBoost` – increase volume on specific dates.
- `activityLevels` – adjust how many users are heavy/medium/normal/low activity.
- Message pools (`WORK_SENTENCES`, `CASUAL_SENTENCES`, etc.)
- Media URLs, emojis, tags, and task titles.

## Verification
After the script finishes, you can verify the data with:
```bash
mongo --eval "db.chatmessages.countDocuments({ roomId: <GENERAL_ROOM_ID> })"
```
Or use the API/UI to view the GENERAL chat and scroll through the timeline – you should see continuous activity for every day between the dates.
